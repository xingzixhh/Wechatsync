## 一般不用改（除非你要彻底换包名）

- npm 包名 `@wechatsync/*`、日志前缀 `Wechatsync`
- 根目录 `README.md` 上游介绍（可另写 `_doc` 说明，不必整篇改成营销文）

包名大改牵涉面大，**只改给人看的中文名 + 图标**就够日常自用。

---

## 推荐操作顺序

1. 定好显示名 / 描述 / 短名 / 图标  
2. 改 `manifest.json` + 图标 + popup 标题页  
3. `pnpm build:extension`（或开着 `pnpm dev`）  
4. 扩展管理页 **重新加载**  
5. 按「最小验收」点一遍（见 `01` 第四节）  
6. 再改悬浮按钮、右键菜单、关于页链接  
7. 再重新加载，打开真实文章页确认  
8. 满意后提交推到 `origin`（你们的 GitHub）

---

## 怎么验（品牌专用）

- [ ] `chrome://extensions` 里名称、描述已是新文案  
- [ ] 工具栏图标已是新图标  
- [ ] popup 首页标题正确  
- [ ] 关于页无旧名、链接指向你们仓库（若已改）  
- [ ] 文章页悬浮按钮 / 右键菜单短名正确  
- [ ] 同步对话框内无明显旧品牌文案  

**不必**为了改名字去各平台真发文；真发草稿验收留给改同步逻辑时再做。
